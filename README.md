# DSH AppHub

运行在 DeepSeek Harness 内的应用入口。独立仓库，使用官方扩展接口，不 fork 或修改宿主。

备忘录进入维护期；收藏夹基础功能已接入现有 DSH 桌面，支持手动管理与 Chrome 导出的书签 HTML。

## 当前功能

- 首页采用紧凑应用目录，登记备忘录与收藏夹；无连接检查按钮、成功时间或虚假推荐。
- 任务框直接输入要求，或使用 `@备忘录` / `@备忘录/新建`，进入备忘录，由 DSH 的既有模型生成并调用工具保存。`@备忘录/打开` 直接打开应用。
- 备忘录参考叠笺的全部备忘录页面：搜索、便签/归档列表、标题与正文、纸色、置顶、归档/恢复、自动保存。窄容器显示单列列表，720/1100px 起分别显示 2/3 列小便签；编辑弹层限制尺寸。
- 备忘录只在 AppHub 内呈现断点适配的便签集合，点击后展开编辑，不再提供右侧卡片栈或聊天侧栏入口。
- 首页使用 DSH 会话导航，不额外提供“返回聊天”按钮。首页齿轮仅修改 AppHub 外观；应用行菜单、备忘录内的外观按钮只修改备忘录。两者分别持久化，点击外观选项直接应用，无保存按钮，均不改 DSH 全局设置。

停止输入约 350ms 自动保存；失败保留草稿，仅失败时出现重试操作。以实际 Host 回执表示保存成功；未确认编辑有本地恢复日志，重开后可恢复，冲突恢复为副本。任务等待会话结束并核对保存操作汇总，部分失败保留异常入口，完成只刷新列表。

## 收藏夹

- 添加、编辑、移除链接；标题、说明、标签与集合；搜索和卡片/列表切换。
- 点击“导入书签”选择 Chrome 导出的 HTML，预览后确认；保留文件夹路径，按 URL 去重，不覆盖人工标题、说明和标签。重复导入不恢复已移除条目。
- 单文件最多 10 MB、10000 条链接；只接受不带账号密码的 HTTP(S) 链接。导入在一个事务内完成，失败不留下部分写入。
- 收藏夹已有 AI 收集和归类工具，支持分批保存、复用集合、用途标签和独立 AI 说明；个人备注不被覆盖。任务入口跟随当前集合，提交后固定上下文。
- 列表服务端分页，每页 60 条；预览队列并发 2，优先当前页，成功后按项显示封面/图标。经授权配置官方代理后，已在原桌面验证五个网站的封面及重启缓存；不绕过地址校验，不保证所有网站有封面。GitHub Stars 和 Chrome 实时同步暂缓。

## 收藏导出与会话交接

收藏夹的导出菜单支持 Markdown、浏览器书签 HTML、JSON，以及携带 JSON 附件进入 DSH 新会话。范围为当前集合和搜索条件的全部匹配项，不限于已加载页面；超过 10000 条或 20 MB 明确拒绝，不静默截断。JSON 保留业务字段，不包含预览缓存；HTML 保留集合目录，多集合链接会出现在对应目录中。

新会话入口填写任务后点击“创建并执行”，复用 DSH 的文件上传与会话接口，提交成功后打开会话。此操作会执行模型任务，不是未发送草稿。附件是导出时的快照；不自动发送飞书，也不承诺 super-agent 可用。上传或提交失败不自动重发。

## 当前接入

使用用户正在使用的 DSH 桌面和原有 profile，通过本地 `node_modules/dsh-apphub` 链接与既有 patch 中的单一启用条目加载。未改账号、模型凭据、其他插件配置。Host 接口变化需要重启同一应用；Client 构建可由宿主热加载。

本仓库和 `lib/` 构建产物需保留；当前不是正式分发安装包。宿主重新安装依赖后需核对开发链接。

```sh
npm ci
npm run check:boundaries
npm run build
npm test
```

基线：官方 DSH 0.2.1-rc.5，Node 24.22.1。`npm run build` 包含官方 Typert 契约生成、类型检查及两端打包。不启动浏览器版或额外测试实例。

## 代码边界

```text
src/ui/                 首页、共享便签界面与设置，仅接收状态和回调
src/application/        业务校验、编辑/请求控制器、任务能力定义
src/contracts.ts        JSON 数据契约
src/adapter/host/       DSH Remote 服务与可信工具调用适配
src/adapter/storage/    SQLite 版本迁移与持久化
src/adapter/client/     官方主面板、会话调度与生命周期适配
```

AppHub 公共数据位于当前 DSH_HOME 的 `apphub/hub.sqlite`，备忘录与其设置位于 `apphub/apps/notes/data.sqlite`；收藏夹独立存于 `apphub/apps/bookmarks/data.sqlite`。旧 `apphub/notes.sqlite` 校验迁移后保留，独立于原 StackedNotes 用户数据。叠笺为 SwiftUI/AppKit，不能直接把其窗口代码嵌入 DSH；本项目沿用其交互规则并适配宿主接口，不读取或改写原应用的数据。

已按用户最新要求移除侧边卡片栈和聊天侧栏接入。手机连接、固定草稿撕纸、导出、拖拽排序与跨 App 调度尚未迁入。任务刷新恢复与完整插件卸载测试的限制见状态文档。
