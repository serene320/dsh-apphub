# 收藏夹首版范围

更新：2026-11-03。用户最新要求优先：完成 AI 批量收集、分组、网页预览链路，并兼容 Chrome 导出的书签文件；不做账号导入或实时同步。

## 本轮交付

- 手动添加、编辑、移除 HTTP(S) 链接；标题、说明、标签、集合、搜索、卡片/列表切换。
- Chrome/Netscape bookmarks HTML 文件选择、预览与确认导入；保留文件夹路径，URL 去重，重复导入不覆盖人工字段、不恢复已移除条目。
- AI 查询收藏/集合、每批 1–20 条创建、按版本调整标签/集合；一次任务可多批、多任务互不独占。默认复用已有集合，独立保存用途说明和来源，不覆盖个人字段。
- 大量链接使用服务端分页（60 条/页）、数据库筛选与集合搜索。真实任务保存回执驱动列表刷新；任务入口显示所选集合及新增/已有结果。
- 独立业务服务、控制器与 SQLite 数据库；UI 只接收状态和回调，复用 DSH 通用控件与主题。
- 当前桌面验证添加、编辑、搜索、集合筛选、导入、重复导入、重启后保留；故障与版本冲突使用合成测试。

## 明确暂缓

GitHub Stars/Projects、凭据与 OAuth、Chrome 扩展/实时同步、离线正文、截图服务、向量库与跨应用工作流。

不改宿主、不另开实例、不调整代理或绕过公网校验。预览提取、二进制校验、资源路由、缓存与懒加载已实现；当前 Host 公共抓取被非公网 DNS 校验阻塞，真实网页封面仍未验收。AI 可通过 DSH 搜索/浏览器工具核实入口，不意味着 Host 预览网络已经可用。

## 后续接入边界

收藏仓储接口与数据契约保留稳定 ID、版本和删除标记；HTML 只是 Host 输入适配器。未来浏览器扩展或其他来源仍进入同一业务服务，不直接访问数据库。实时同步协议仍待明确授权；AI 调用权限按操作和可信会话校验，AppHub 已绑定任务不能写入另一应用。本轮只增加有上限的预览队列，不建通用任务平台。

本轮验收通过后先使用，再根据实际需求选下一步，不自动推进暂缓项。架构与限制见 [architecture.md](architecture.md#收藏夹基础架构)，能力核查见 [references.md](references.md#收藏夹能力核查2026-11-03)。
