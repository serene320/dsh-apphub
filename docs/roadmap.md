# 下一阶段：收藏夹

更新：2026-11-03。本轮授权为源码检查与方案整理，不代表实现、安装、账号授权或外部调用验收。

## 首版范围

- 网页收藏：单条/多行 URL 添加、标题、个人说明、标签、集合、搜索、卡片/列表切换、编辑和移除本地收藏。
- 预览：站点图标、Open Graph 封面/标题/简介；GitHub 仓库显示结构化项目信息。没有图片时使用紧凑文字卡片，不占空图区域；失败不阻塞收藏保存。
- 浏览器导入：Netscape bookmarks HTML；预览数量、无效项及文件夹树，可选目录导入，保留集合层级与可用时间。首版不直接读取浏览器数据库。
- GitHub Stars：公开用户名导入；需要认证时使用用户显式提供的只读凭据，经 DSH 凭据服务保存。分页、限流、取消、重复导入去重。私密资料只限凭据可见范围，空结果不能武断解释为没有 Stars。
- AI：添加、查找、修改明确选中的收藏、分类；网页简介与 AI 总结分开。导入和凭据设置由人发起，不作为模型可调用操作。
- 导入先保存条目，用户可选择是否补全网页预览；补全使用小并发队列，支持取消与失败重试。重新导入不覆盖人工编辑，也不因远端取消 Star 而删除本地条目。

暂不做：网页截图服务、完整网页内嵌、正文离线归档、浏览器扩展/实时双向同步、向量库、定时抓取、跨应用工作流、GitHub Projects 看板、OAuth 应用注册。旅行与模型选择继续暂缓。

## 实施顺序与出口

1. **最小技术验证**：原 DSH 桌面选择一个合成书签 HTML；以宿主传输显示一张受控图片；确认现有 ctx.web、connection、credentials 服务可用。只验证必要接口，不增加正式页面或修改宿主。不以源码存在冒充当前桌面可用。
2. **本地收藏闭环**：独立数据库、共用应用定义与显式任务目标、增改查/集合/卡片。备忘录行为回归通过，切换应用不改变运行中任务目标。
3. **预览与 HTML 导入**：公共网页元信息、受限图片缓存、目录选择、导入进度与去重。包含无封面、超时、错误文件、重复导入和取消案例。
4. **Stars 导入与 AI**：公开用户名/显式只读凭据两条路径，分页与限流；一任务多收藏、与备忘录同时执行互不串数据。没有用户账号授权时只做合成接口测试，不宣称真实 Stars 已验收。

第一版完成标准：浏览器 HTML 与 Stars 导入同一 GitHub 仓库后只有一条收藏、两个来源；人工标签和标题保留；预览失败仍可使用；重开后数据一致；列表不因补图整页闪烁。普通网页不能通过预览请求访问本机或私网。

## 当前限制与决策

DSH 提供基础能力，没有现成收藏应用或通用导入服务。图片获取与元信息解析需要 AppHub 薄适配；授权存储可复用，但没有发现专用 GitHub Stars 登录 flow。先使用公开用户名和必要时只读凭据，不为首版另建 OAuth 平台。若后续需要一键登录，再注册自己的 GitHub App/OAuth App 并接入 DSH authorization。

技术验证发现的能力缺失只影响对应功能，不引入宿主 patch、私有深层导入或额外浏览器实例。具体复用证据见 [references.md](references.md#收藏夹能力核查2026-11-03)，分层与数据设计见 [architecture.md](architecture.md#收藏夹架构拟定)。
