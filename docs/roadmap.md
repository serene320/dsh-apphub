# 收藏夹首版范围

更新：2026-11-03。用户最新要求优先：先完成基础功能，并兼容 Chrome 导出的书签文件；不做账号导入或实时同步。

## 本轮交付

- 手动添加、编辑、移除 HTTP(S) 链接；标题、说明、标签、集合、搜索、卡片/列表切换。
- Chrome/Netscape bookmarks HTML 文件选择、预览与确认导入；保留文件夹路径，URL 去重，重复导入不覆盖人工字段、不恢复已移除条目。
- 独立业务服务、控制器与 SQLite 数据库；UI 只接收状态和回调，复用 DSH 通用控件与主题。
- 当前桌面验证添加、编辑、搜索、集合筛选、导入、重复导入、重启后保留；故障与版本冲突使用合成测试。

## 明确暂缓

网页封面与元信息抓取（当前公共抓取被非公网 DNS 校验阻塞）、GitHub Stars/Projects、凭据与 OAuth、Chrome 扩展/实时同步、收藏夹 AI 工具、批量任务、离线正文、截图服务、向量库与跨应用工作流。

不改宿主、不另开实例、不调整代理或绕过公网校验。图片显示和本地文件传输已有独立验证，但不能据此宣称真实网页预览已完成。

## 后续接入边界

收藏仓储接口与数据契约保留稳定 ID、版本和删除标记；HTML 只是 Host 输入适配器。未来浏览器扩展或其他来源仍进入同一业务服务，不直接访问数据库。实际同步协议、冲突策略和 AI 权限应在明确授权后另做最小实现；本轮不预建队列或通用插件框架。

本轮验收通过后先使用，再根据实际需求选下一步，不自动推进暂缓项。架构与限制见 [architecture.md](architecture.md#收藏夹基础架构)，能力核查见 [references.md](references.md#收藏夹能力核查2026-11-03)。
